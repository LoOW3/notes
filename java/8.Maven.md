Maven es una herramienta de software para la gestion y construccion de proyectos Java que se caracteriza por tener un modelo de configuracion muy simple, basado en el formato XML.

Maven utiliza el conocido archivo POM.xml (Proyect Object Model) para dentro de el especificar las diferentes dependencias o libreiras que seran necesaria incluir en  el proyecto que se este desarrollando.

Algunos ejemplos de IDEs que ya incluyen Maven como opcion en la creacion de proyectos son:
- Intellij IDEA
- Netbeans
