# Arquitectura Monolitica

- La aplicacion monolitica esta contenida en un solo modelado de clases
- Posee una sola logica de negocio
- Posee una sola base de datos centralizada para toda la aplicacion
- Todo el codigo fuente de la aplicacion se encuentra en un solo proyecto, que se compila en un solo archivo ejecutable


- faciles de mantener
- no dependemos de servicios o aplicaciones externas
- Gran compleijdad al crecer a gran escala
