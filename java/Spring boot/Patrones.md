# Patrón PROXY

## Que es un Object Proxy?
Es un objeto que agrega logica adicional por encima del objeto que esta siendo "proxiado" sin necesidad de modificar el codigo del objeto proxiado. Un objeto proxy tiene los mismos metodos publicos que el objeto proxiado y deberia ser lo mas posible indistinguible.
